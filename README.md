# Sistema Básico de Gestión de Garaje

Aplicación de escritorio desarrollada en Python utilizando Tkinter.

## Descripción

El sistema permite registrar vehículos que ingresan a un garaje y visualizar la información dentro de una interfaz gráfica.

Cada vehículo contiene:

- Placa
- Marca
- Propietario

## Funcionalidades

- Registrar vehículos
- Mostrar vehículos registrados en una lista
- Limpiar campos del formulario

## Tecnologías utilizadas

- Python
- Tkinter
